# 巧克力小镇 · 2026 年 10 月 3 日

以 `photos/` 中的 19 张实拍为依据建立的本地交互式微缩展示。

## 打开

在本目录运行：

```powershell
powershell -NoProfile -File .\scripts\start-preview.ps1
```

脚本在后台启动，返回本次实际地址。把输出的 `http://127.0.0.1:端口` 复制到浏览器。端口自动分配，不需要修改浏览器或系统设置。也可以在已有终端运行 `npm start`。不要直接双击 HTML，ES 模块需要 HTTP。

无需联网或再次安装依赖即可预览：Three.js 的浏览器运行文件已保存在 `public/vendor/`。

## 使用

- 拖拽旋转，滚轮 / 双指缩放，右键拖拽平移。
- 点击建筑、浮动地标或底部卡片，查看对应照片与空间依据。
- 店铺已疏开，巴士移到左前侧。点击店铺后镜头更正面地对准立面，并避开桌面侧栏或手机底部照片栏。
- 左侧「地点目录」包含所有节点，包括未定位的月亮展墙和楼梯。
- 右侧工具依次为：初始视角、俯瞰、放大、缩小、柔光 / 夜景、保存画面。
- 「实拍档案」保留全部 19 张原图；灯箱支持左右方向键和 Escape。
- 减少动态效果偏好会禁用自动过渡，自动环绕仅在手动点击后开启。
- 无 WebGL 时仍能浏览实拍档案。

## 真实性边界

这是**基于照片的人工微缩重构，不是摄影测量、全景拼接或精确数字孪生**。

店面细节与局部邻接来自实拍。街段之间的连接、尺寸、建筑厚度及不可见背面是展示性推定。舞台移除了实际室内场景的展馆顶棚；没有对场地全覆盖作出承诺。模型路线、朝向与文件编号均不可作为实际导航依据。

已知关系：

| 依据 | 可确认内容 |
| --- | --- |
| 照片 10 | 餐厅—邮局—面包店同框 |
| 照片 14、15 | 裁缝店—饰品店街角，玩具店与书店相邻 |
| 照片 11、17 | 巴士与公告栏；巴士照片右侧可见餐厅 |
| 照片 12、13、16 | 品酒屋与红色橱窗 |
| 照片 1、18、19 | 月亮展墙与楼梯无法定位，仅作为实拍节点 |

原文件未包含 EXIF、GPS 或拍摄时间。网页日期依据用户提供的拍摄日，不是从 EXIF 解析。网页照片编号 01—19 对应原文件末段序号 41—59。完整元数据见 `analysis/photo-metadata.json`。

## 文件

- `photos/`：用户原件，未修改。
- `public/photos/`：逐字节相同的展示副本。
- `public/town.js`：3D 模型、相机和照片纹理。
- `public/data.js`：地标、照片及依据清单。
- `public/layout.js`：展台、路灯与详情镜头构图配置。
- `public/app.js`、`style.css`、`index.html`：交互展示。
- `scripts/server.mjs`：仅回环监听的静态服务器，不提供目录浏览。
- `.preview/server.json`：本任务服务的 PID、工作目录与真实端口。
- `.preview/stdout.log`、`stderr.log`：任务日志。
- `docs/plans/`：设计与实施说明。
