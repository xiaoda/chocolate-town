# 店铺疏开与巴士移位

## 用户要求
店铺稍微分散，巴士不要挡在店前，方便详细观察。保留照片、地标关联、建筑大小和现有视觉风格。

## 方案
不通过缩小建筑或隐藏车辆来制造空隙。将原有店铺中心向外疏开约 30%，维持店铺分组与顺序；同步扩展展台并调整路灯、路径。巴士与公告栏移到左前侧，远离主店铺的观察轴线。巴士方位统一由数据驱动。

详情镜头正对所选建筑，完整容纳店面与楼层；按照侧栏实际占用的屏幕区域计算构图。手机详情占下方，模型投影上移到未被面板覆盖的区域。详细观察时只保留当前地标标签，减少其他标签遮挡。

## 实施与验证
1. `tests/layout.test.mjs`：先建立间距、巴士位置、场景边界与镜头构图回归测试。
2. `public/data.js`：更新店铺及巴士坐标、巴士说明。
3. `public/layout.js`：集中展台尺寸、路灯、公告栏与纯函数镜头计算。
4. `public/town.js`：采用新布局、更新全貌与详情镜头，保留静态合批优化。
5. 运行 `npm test`，在本任务浏览器检查全貌、书店、左侧裁缝店、右侧品酒屋，以及手机详情。记录测试结果。

布局仍为方便展示而推定，不宣称移动后的位置是实地测量结果。复用已确认归属的本地预览服务，不启动重复服务。
